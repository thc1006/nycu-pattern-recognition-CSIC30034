# 審查清單

## 資料與實驗設計

- [ ] 資料產生與題目的每個數字一致（類別數、每類筆數、平均數、共變異數、雜訊變異數；變異數與標準差沒有搞混）。
- [ ] 分割是分層的，比例正確，訓練與測試不重疊。
- [ ] 平均數、共變異數、標準化、PCA、LDA 只用訓練集估計（改動測試資料不會影響訓練端轉換）。
- [ ] 重複次數與種子寫在結果檔；同一次重複內各方法共用分割。
- [ ] 掃描範圍完整（例如維度 1 到 100 每個值都有）。

## 方法

- [ ] 距離、共變異數分母、散布矩陣權重與講義一致；與講義不同的選擇在報告中寫明。
- [ ] 奇異矩陣的處理方式寫明，圖上標出奇異區；結果的怪異之處有解釋而不是被藏起來。
- [ ] 白化與 ridge 的公式和程式一致（縮放的是哪個特徵值、ridge 加在哪個矩陣）。
- [ ] 不在測試集上挑參數；若有「最佳」的說法，說明是固定網格下的觀察。

## 數字與敘述

- [ ] 報告中每個數字都能從結果檔重算出來，四捨五入一致。
- [ ] 表格與正文的同一個數字相同。
- [ ] 「最高、最低、重合、都低於、之後最好」這類敘述有 assert 或手算證據。
- [ ] 理論敘述經過小實驗驗證（例如可逆線性轉換下 MD 不變、秩上界、擬反矩陣下訓練點的距離）。
- [ ] 解釋的因果鏈每一步都有證據；沒有證據的只寫觀察。

## 圖表

- [ ] 每張圖都在正文被引用，引用的子圖編號正確。
- [ ] 軸標籤、單位、圖例完整；顏色在各圖代表同一件事。
- [ ] 圖說寫清楚資料、分割、重複次數、色帶或誤差線的意義。
- [ ] PDF 中沒有 Type 3 字型、缺字、繪圖器警告。

## 文件

- [ ] 正文不超過頁數限制，附錄在同一個 PDF，附錄程式即實際執行的檔案。
- [ ] 首頁有姓名、學號（與信箱，若要求）。
- [ ] 用語為台灣用法，`scan_zh_tells.py` 沒有提示，或每筆都確認過。
- [ ] README 的指令能在乾淨環境照著跑完。
