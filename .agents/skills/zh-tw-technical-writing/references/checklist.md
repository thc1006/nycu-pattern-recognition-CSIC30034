# 檢查清單與改寫範例

下面這些寫法都會降低資訊量，看到就改。

## 句式

| 寫法 | 例 | 改寫 |
|---|---|---|
| 翻案句 | PCA 白化不是單純縮放，而是去相關轉換 | PCA 白化把資料投影到特徵向量上，再把第 i 軸除以 √λᵢ，轉換後共變異數為 I |
| 防禦性否定 | 不能把這段回升說成雜訊有幫助 | 這段回升來自分類規則改變 |
| 不僅…更… | 正則化不僅解決奇異問題，更提升穩定性 | Σ̂+γI 的最小特徵值至少為 γ，因此可逆 |
| 路標詞 | 值得注意的是，n<d 時共變異數不可逆 | n<d 時樣本共變異數的秩至多 n−1，所以不可逆 |
| 複述句 | d=k 時錯誤率最低。這意味著特徵並非越多越好 | d=k 時錯誤率最低，再加特徵反而上升 |
| 萬用開場 | 隨著大數據時代來臨…… | 本作業在 Iris（150 筆、4 維、3 類）上比較…… |
| 結尾套話 | 綜上所述，本實驗充分證明正則化的重要性 | 結論段只寫數字與適用條件 |
| 三連排比 | 提升穩定性、增強泛化、降低風險 | 只寫實際量到的那一項 |
| 扮演角色 | 共變異數在 LDA 中扮演關鍵角色 | LDA 的方向是 (S_w+γI)⁻¹S_b 的特徵向量 |
| 提示性冒號 | 關鍵在於：Σ 必須可逆 | Σ 必須可逆 |
| 自問自答 | 為何兩個 PCA 軸就夠？因為…… | 兩個 PCA 軸就夠，因為…… |

## 翻譯腔與名詞化

| 寫法 | 改寫 |
|---|---|
| 對資料進行標準化處理 | 將資料標準化 |
| 實現了錯誤率的降低 | 錯誤率由 a% 降為 b% |
| 對於 1-NN 來說，尺度很重要 | 1-NN 對特徵尺度敏感 |
| 作為一種線性分類器，LDA…… | LDA 是線性分類器…… |
| 通過引入正則項來提升穩定性 | 加入 γI 後…… |

數學條件句可以保留「當……時」；術語命名可用被動（稱為 Hughes 現象）。

## 段落與結構

- 段末小結、金句收尾：刪。
- 段首評論要回指上文或直接寫事實。
- 每節不必三點、等長；篇幅依重要性分配。
- 小標題照題號，不必每段一個。
- 同一觀點不要在不同段落重講；同一概念只用一個詞。

## 內容

- 缺數字：每個結論附數值與評估方式。
- 與實驗無關的大趨勢句：刪。
- 模糊歸因（研究表明……）：引用真的讀過的來源，或刪掉。
- 免責堆疊（結果可能受多種因素影響）：改成具體限制，例如「每類只有 25 筆訓練資料」。
- 為了完整而補齊（未來可擴展……）：沒做的事不寫。
- 寫出自己的判斷：為什麼選這個 γ、奇異時怎麼處理。

## 圖、表與程式

- 圖說描述畫了什麼（資料、分割、重複次數、色帶意義），詮釋留給正文；不以「本圖顯示」開頭。
- 正文引用具體數值並指向圖號；同一組數字不要在表與正文重複整列。
- 圖中英文標題用 sentence case；圖例名稱與正文用詞一致。
- 程式註解只寫原因與數學對應，不逐行敘述；不用 emoji、`# Step 1`；不要到處 try/except。
