# 台灣用語對照

統計與機器學習名詞以國家教育研究院樂詞網為主，IT 用語參考 OpenCC 台灣詞組表。

| 避免（大陸常見） | 使用（台灣） |
|---|---|
| 方差 | 變異數 |
| 協方差（矩陣） | 共變異數（矩陣） |
| 均值 | 平均數、平均 |
| 偽逆 | 擬反矩陣（pseudo-inverse） |
| 逆矩陣 | 反矩陣 |
| 本征值 | 特徵值 |
| 噪聲 | 雜訊 |
| 概率 | 機率 |
| 正態分布 | 常態分布 |
| 似然 | 概似、概度（最大概似估計） |
| 回歸、嶺回歸 | 迴歸、脊迴歸 |
| 魯棒 | 穩健 |
| 過擬合 | 過度擬合 |
| 歸一化 | 正規化、標準化（z-score） |
| 散佈矩陣（scatter） | 散布矩陣 |
| 樣本量 | 樣本數 |
| 模式識別 | 圖形識別 |
| 數據 | 資料 |
| 信息 | 資訊 |
| 質量 | 品質 |
| 默認 | 預設 |
| 優化 | 最佳化 |
| 運行 | 執行 |
| 算法 | 演算法 |
| 實現（implement） | 實作 |
| 軟件 | 軟體 |
| 程序（program） | 程式 |
| 代碼 | 程式碼 |
| 文件（file） | 檔案 |
| 打印 | 列印 |
| 視頻 | 影片 |
| 網絡 | 網路 |
| 數組 | 陣列 |
| 變量 | 變數 |
| 圖像 | 影像 |
| 採樣 | 取樣 |
| 項目（project） | 專案 |
| 通過（手段） | 透過 |

兩岸相同、可直接用：正則化（regularization，不要寫成正規化以免和 normalization 混淆）、標準化、白化、主成分、特徵向量、向量、矩陣、樣本、條件數、奇異矩陣、決策邊界、準確率。

數學內文寫「函數」「參數」；「函式」「引數」是程式用語（function、argument）。
